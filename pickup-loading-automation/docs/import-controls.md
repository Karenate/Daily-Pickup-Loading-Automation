# Import Actions (Only)

| Action | VBA macro | Outcome |
|---|---|---|
| Import Product A | `Import_A` | Loads A only; shows A summary |
| Import Product B | `Import_B` | Loads B only; shows B summary |
| Import Product C | `Import_C` | Loads C only; shows C summary |
| Import All | `Import_All` | Runs A, B, C and displays per-product summaries |

The demo does not include a new-month button, a refresh button, or a control-panel worksheet. Existing daily dates are preserved.
